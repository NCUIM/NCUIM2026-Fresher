# Impression 一律具名，且僅收件人可見

Impression 是這個系統裡唯一「由使用者撰寫、內容關於另一個特定真人」的資料。它一律具名（收件人看得到是誰寫的），且只有收件人與 Admin 看得到；收件人可隨時隱藏個別 Impression，並在隱藏時一併回報給 Admin。

## 為什麼不匿名

匿名有兩個問題，而第二個比第一個更關鍵：

**匿名是騷擾的溫床。** 使用對象是七十位剛成年、彼此陌生的新生，這正是惡意留言最容易出現的場合。具名幾乎能消除這個風險——極少有人願意用自己的名字寫難聽的話給剛認識的人。

**匿名會讓這個功能失去意義。** 整場活動的目的是認識新朋友。「小明說我很幽默」讓你記住了小明這個人；「有人說我很幽默」則什麼也沒留下。匿名把一份具體的人際連結降級成一句無主的評語。

「由書寫者自行選擇是否具名」看似兼顧兩者，實際上只要開放匿名選項，想寫惡意內容的人就會選它，等同沒有防護。

## 為什麼不公開

把 Impression Wall 對所有人開放會更「社群」，但它會創造出**第二條受歡迎程度的比較軸線**：「他的牆上有三十則，我只有三則」。

這與 Leaderboard 有本質差異。Leaderboard 衡量的是主動掃描數，是努力就能改變的；「有多少人願意寫東西給我」則衡量受歡迎程度，努力也改變不了。落在後段的人只會受傷，而這與活動想達成的效果完全相反。

同理，Showcase 雖然公開可瀏覽，但系統**不提供「我被幾個人放入 Showcase」的反向查詢**——一旦把這個數字端到使用者面前，它就變成同一條比較軸線。

## Consequences

Impression 屬於收件人，不屬於書寫者。書寫者送出後無法得知對方是否讀過、是否隱藏。

Admin 能看到所有 Impression，這是審核所必需的；後台需明確標示這一點，避免 Admin 誤以為自己在窺看私人內容。

Impression 與其他資料一同在 Event 封存滿十四天後刪除。由於它是系統中最值得保留的內容，Impression Wall 上需明確顯示刪除日期，讓使用者自行決定是否留存。
